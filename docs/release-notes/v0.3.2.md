# v0.3.2 — bugfix release

Three real CLI bugs found while recording the demo GIFs, each now covered by a
spawned-CLI regression test (test suite: 129 → 132).

## Fixed

- **`handoff` silently skipped propagation.** The `--no-sync` option carried an
  explicit `false` default, which commander turned into `options.sync === false`
  even when the flag was absent — so every `syncytium handoff` ran with
  propagation disabled while still printing "propagated to all AI tools".
  Bridge files (CLAUDE.md, AGENTS.md, …) only updated if you ran `sync` by
  hand, and the CI drift-gate fired false alarms after every handoff.
- **`diff --full` printed the patch one character per line.** The code iterated
  the raw patch string instead of splitting it into lines. `--full` now shows up
  to 200 real patch lines.
- **`graph --no-files` / `--no-tags` / `--no-open` inverted their defaults.**
  The same commander negatable-option pitfall: file and tag nodes were hidden by
  default and the browser always opened. Defaults now match the documented
  behaviour.

## Why it matters

If you script handoffs in a multi-agent workflow (the main reason to use
SyncytiumMD), v0.3.1 left every bridge file stale and lied about it. Upgrade:

```bash
npm install -g syncytium-md@0.3.2
```
